# Normalización y lematización de texto

Actividad del Bloque 3 de Procesamiento de Lenguaje Natural.

El proyecto procesa el libro Lazarillo de Tormes mediante spaCy y su modelo en español.

## Procesos aplicados

- Carga del archivo de texto.
- Tokenización.
- Conversión a minúsculas.
- Eliminación de stop words.
- Eliminación de puntuación y espacios.
- Lematización.
- Generación de un archivo con el texto normalizado.

## Ejecución

Instalar las dependencias:

pip install -r requirements.txt

Ejecutar el programa:

python normalizar.py
